# 🖨️ WebPrint — Epson L360 Kiosk Interface

Antarmuka web modern berbasis **Glassmorphism Dark Galaxy Theme** untuk sistem pencetakan, pemindaian, dan fotokopi mandiri pada printer Epson L360.

---

## ✨ Fitur Utama

- **Galaxy Canvas Animation**: Efek latar belakang partikel bintang dinamis.
- **Glassmorphism UI**: Efek frosted-glass dengan aksen warna gold `#F4C500` dan navy blue `#18497B`.
- **Mobile-First / Kiosk Ready**: Desain layout responsif dengan sticky navigation bar untuk layar HP maupun kiosk tablet.
- **Modul Layanan**:
  - 🖨️ **Cetak Dokumen**: Drag & drop file PDF, JPG, PNG serta opsi cetak fleksibel.
  - 📄 **Pemindai**: Pengaturan DPI (150/300) dan mode warna scanner.
  - 📑 **Direct Copy**: Cetak fotokopi langsung dengan pengaturan rangkap.
  - 📋 **Antrean Tugas**: Pemantauan status pengerjaan dokumen.
